🧑‍💼 Admin User Stories

These are users who have access to the full dashboard interface and control the system.
🔐 Authentication

    As an admin, I want to log into the feedback dashboard securely so that I can manage feedback.

📩 Invitations

    As an admin, I want to send invitation links to new members via email so they can submit feedback.

📥 Feedback Management

    As an admin, I want to view all submitted feedback so I can address team concerns.

    As an admin, I want to filter feedback by status (e.g., pending, addressed) so I can manage my workflow.

    As an admin, I want to see whether feedback is anonymous or attributed so I can respond accordingly.

    As an admin, I want to assign feedback to other admins so responsibilities are shared.

    As an admin, I want to update the status of feedback so we can track progress.

👤 Member User Stories

These users are invited and can submit feedback, anonymously or with identity.
📨 Invitation & Access

    As a member, I want to receive an invitation via email with a link so I can submit feedback.

✍️ Feedback Submission

    As a member, I want to write and submit feedback so that I can share my thoughts with admins.

    As a member, I want to choose to submit feedback anonymously or with my name so I feel safe expressing myself.

💡 Optional / Future Stories (Stretch Goals)

    As an admin, I want to receive notifications when new feedback is submitted.

    As a member, I want to see the status of feedback I submitted (if not anonymous).

    As a member, I want to submit follow-up feedback if my previous one is unresolved.
